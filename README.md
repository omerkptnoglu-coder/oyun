# Oyun

Tarayıcıda çalışan basit bir oyun. Oynamak için `index.html` dosyasını tarayıcıda aç.

## Freze Devir Hesabı (mobil uygulama)

`freze/` klasöründe, frezede parmak freze, tarama kafası, matkap, rayba ve kılavuz için
devir (S, dev/dk), ilerleme (F, mm/dk), Fz (mm/diş), Vc (m/dk) ve paso (ap/ae) hesaplayan
bir mobil web uygulaması (PWA) bulunur. Telefonda açıp "Ana ekrana ekle" ile uygulama gibi
kurulabilir; kurulduktan sonra internetsiz çalışır.

GitHub Pages açıksa adres: `https://<kullanıcı>.github.io/oyun/freze/`
